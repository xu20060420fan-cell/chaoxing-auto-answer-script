# 智能自动答题助手

本仓库包含两部分：

*   **`超新学习通答题脚本.js`** — 智能自动答题助手（油猴用户脚本，v1.8）
*   **`刷课题库/`** — 配套的远程题库服务，为脚本提供统一答题查询接口

---

## 一、智能自动答题助手（用户脚本）

一个油猴用户脚本，运行在浏览器中，用于自动完成在线网课的题目和视频学习。

### 主要功能

1. 自动检测网页中的题目，支持单选题、多选题、判断题、填空题、简答题
2. 支持接入多种 AI 大模型进行答题，包括 OpenAI GPT、Anthropic Claude、Google Gemini、百度文心一言、阿里通义千问、月之暗面 Kimi、智谱 GLM、深度求索 DeepSeek、MiniMax、商汤日日新、小米 MiMo、字节豆包，同时也支持自定义 API 接入
3. 支持通过 Bing、Google、百度 三个搜索引擎搜题，AI 答不上来时使用搜题结果兜底
4. 支持自定义题库，可添加多个题库进行融合答题，每个题库支持自定义请求方法、请求头、请求体、响应解析脚本
5. 支持答题缓存，答过的题目会缓存下来，再次遇到相同题目会直接使用缓存答案
6. 支持双 API 对比模式，启用后会调用两个 AI 同步答题，答案一致才填写，提升准确率
7. 支持内置网站白名单，覆盖超星学习通、智慧树、雨课堂、中国大学 MOOC、职教云、智慧职教、高校邦、对分易等常见网课平台，同时也支持用户自定义添加白名单
8. 支持题目类型过滤，可以选择只做某种类型的题目，例如只做单选题不提交填空
9. 支持多种答题起始模式，包括从头开始、从未做的题目开始、继续上次进度
10. 支持图片题目识别，对于题干包含图片的题目，会自动提取图片信息辅助答题
11. 支持自动填写答案并自动切换到下一题，中间过程无需人工干预
12. 支持刷课功能，进入视频学习页面后可自动完成视频观看，包括视频倍速播放、音量调节、鼠标离开视频时不暂停、自动解除暂停状态、视频结束后自动连播下一个、检测到弹窗时自动关闭
13. 支持视频内嵌题目的自动作答，学习通视频播放过程中弹出的选择题会自动识别并填写
14. 支持自动读章节功能，对于 PPT、书籍、长文本等需要翻页阅读的任务点，可以自动翻页完成阅读
15. 支持自动讨论，章节末的讨论题可以自动发表回复，支持随机回复、第一条、出现最多、点赞最多等多种模式
16. 支持可拖拽的控制面板，悬浮在网页右上角，可以拖动到任意位置
17. 支持运行日志实时显示，可以查看每一道题的答题过程和结果

### 安装与使用

1. 在浏览器中安装油猴插件（Tampermonkey，Chrome/Edge 应用商店搜索即可）
2. 打开 `超新学习通答题脚本.js`，点击「Raw」查看源码，将代码全部复制
   或者直接复制本仓库 `超新学习通答题脚本.js` 的全文
3. 打开油猴插件的「管理面板」→「添加新脚本」，将代码粘贴进去并保存
4. 打开任意一个支持的网课平台页面，页面右上角会出现本脚本的控制面板
5. 在面板的设置页面中填入对应 AI 平台的 API Key，也可以添加自定义题库的 URL
6. 根据需要调整各种开关，例如是否自动填写、是否自动下一题、答题延迟时间等
7. 切换到答题页面，点击开始按钮，脚本会自动开始检测题目并完成作答
8. 如果需要刷课功能，可以在设置中开启刷课开关，进入视频学习页面后脚本会自动开始
9. 如果需要自动讨论，可以在设置中开启讨论开关，脚本会在遇到讨论题时自动发表回复

**油猴（Tampermonkey）下载**：

*   访问 https://www.tampermonkey.net/ ，网页会自动识别当前浏览器并提供对应商店链接
*   或直接在你的浏览器扩展商店中搜索 `Tampermonkey`

## 二、刷课题库服务

「智能自动答题助手」脚本的配套远程题库。提供统一的 `tikuAdapter` 查询接口、模糊匹配引擎、管理后台与批量导入工具。

### 快速开始

```bash
cd 刷课题库
npm install          # 安装 express + cors
node server.js       # 默认监听 8091 端口
```

首次启动若 `data/tiku.json` 为空，会自动导入 `seed/` 下所有题库文件。

**目录结构**

```
刷课题库/
├── server.js          # 服务入口（Express）
├── import.js          # 命令行导入工具
├── admin.html         # 管理后台页面
├── lib/
│   ├── matcher.js     # 归一化 / 相似度 / 答案标准化
│   ├── store.js       # JSON 持久化 + 内存索引（原子落盘 + 备份）
│   └── importer.js    # TSV / JSON / 纯文本 解析
├── seed/
│   └── 计算机网络.csv   # 种子题库（标准内容）
└── data/
    └── remote-sources.example.json  # 远程源示例配置（真实题库 tiku.json 不随仓库分发）
```

### 接入脚本

脚本设置面板 → 题库列表 → 添加题库，URL 填：

```
http://<你的服务器IP>:8091/tiku
```

脚本会自动按 tikuAdapter 协议 POST `{question, options, type}`，返回 `{answer:{allAnswer:[...]}}`。

### 批量导入题库

```bash
node import.js seed/计算机网络.csv
node import.js 我的题库.json json
node import.js 某目录
```

### 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST/GET | `/tiku` | 答题查询（tikuAdapter 协议） |
| GET | `/api/health` | 健康检查 |
| GET | `/api/stats` | 统计 |
| GET | `/api/search?q=` | 模糊搜索预览（带分数） |
| GET | `/api/q?page=&pageSize=&q=` | 分页列表 |
| POST | `/api/add` | 新增单题 |
| POST | `/api/bulk` | 批量导入 |
| PUT | `/api/q/:id` | 修改 |
| DELETE | `/api/q/:id` | 删除 |
| GET | `/` | 管理后台 |

详细说明见 `刷课题库/README.md` 与 `刷课题库/docs/`。
