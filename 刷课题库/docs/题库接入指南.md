# 题库接入指南（2026-09 更新）

> 三条路线按"见效快慢"排序，可同时使用。核心原则不变：**准确率优先，AI 答案未经平台判分验证不直接入库**。

---

## 路线一：星夜题库（免费在线题库，千万级，推荐先做）

**地址**：<https://tiku888.top/>　（OCS 网课助手生态的免费题库平台）

### 步骤

1. 打开 <https://tiku888.top/register> 注册账号（需要 **用户名 + 密码 + 邮箱验证码**，邮箱验证码这一步只能本人完成）。
2. 登录后进 **个人中心 →「题库配置」**，复制 JSON 配置（格式与 OCS 题库配置一致，内含接口地址和 token）。
3. 打开"智能自动答题助手"面板 → 题库设置 → 添加题库，**把整段 JSON 粘贴到 URL 输入框**，点添加。
   - 脚本原生支持 OCS 风格配置（`method/type/data/headers/handler` 全兼容，见 `querySingleTiku`）；
   - 脚本头部已是 `@connect *`，无需改脚本头。
4. 建议同时把同一份配置填进 `data/remote-sources.json`（复制 `remote-sources.example.json` 改名），本地题库服务会作为聚合上游使用。

### 注意

- 未命中时把题干前 15–20 字缩短再试（该平台官方建议）。
- 免费 API 有频率限制，脚本本身 5 秒超时 + 多题库顺序回退，不会卡死。

## 路线二：自采——从自己课程收割题目（最准，答案来自平台判分）

**工具**：`repos/学习通题目导出.user.js`（已下载，v1.7.23，来源
[suyu-ops/chaoxing-question-exporter](https://github.com/suyu-ops/chaoxing-question-exporter)，GPL-3.0）

### 能采到什么

| 页面 | 能采到答案吗 |
|------|--------------|
| 已批阅的考试 / 作业 | ✅ 页面显示正确答案，全量收割 |
| 已提交的章节测验 | ✅ 重进后显示对错与正确答案 |
| 未提交的章节测验 | ❌ 平台未判分，无答案可采（只能采题干） |

### 步骤

1. Tampermonkey → 实用工具 → 导入 `repos/学习通题目导出.user.js`（或新建脚本粘贴内容）。
2. 打开课程学习页，右侧出现"学习通题目一键提取导出"面板。
3. 用 **批量提取章节测验**：它会沿课程任务点列表逐个进入测验页提取，可暂停/继续。
4. 导出为 **JSON**，保存到 `seed/`。
5. 入库：

```bash
cd 刷课题库
node import.js seed/你导出的文件.json json
```

### 说明

- 本脚本只提取**你有权查看的自己课程页面**，与题库建设路线图的合规原则一致。
- 采到的题目走统一去重合并（同题干不覆盖旧答案，只补空缺字段）。

## 路线三：日常沉淀（长期积累，已就绪）

本地题库服务 `POST /api/collect` 接口已实现（`server.js:477`）：

```json
POST http://127.0.0.1:8091/api/collect
{ "question": "题干", "options": ["A文本","B文本"], "type": "单选题",
  "answer": "C", "source": "计算机网络" }
```

用途：以后给主脚本加"判分后回收"钩子（平台显示正确时回写），或手动把做过的题 POST 进去。
**注意**：不建议把未经判分的 AI 答案直接灌库，会污染题库（服务端的次优答案弃答机制能兜一部分，但源头干净更重要）。

## 其他调研结论（2026-09 抓包调研）

| 来源 | 结论 |
|------|------|
| [CxKitty](https://github.com/surinrasu/CxKitty) | Python 工具，章节测验可导出 JSON，但**不附带题库数据**，需配合题库 API |
| [notnotype/xxt](https://github.com/notnotype/xxt) | 超星题库爬虫（自测爬自己课程），JSON 导出；与路线二功能重叠 |
| [lib-hfut 慕课题库](https://github.com/lib-hfut/lib-hfut) | 有真实题库但是 PDF 且多为文化类课程，与在修课程不对口，解析成本高 |
| [cxmooc-tools](https://github.com/CodFrm/cxmooc-tools) | 社区共享题库接口已不稳定，不推荐依赖 |
| 破解付费题库 API | **不做**（路线图原则 5：只分析自有数据，不提供破解代码） |

## 现状

- 本地题库服务：`node server.js` → `http://127.0.0.1:8091/tiku`，当前 87 题（种子）。
- 主脚本接入位置：面板 → 题库设置 → 添加题库（URL 粘贴 `http://<IP>:8091/tiku` 或整段 OCS JSON）。
