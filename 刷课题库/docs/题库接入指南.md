# 智能自动答题助手 · 接入指南（脚本 ↔ 后端 ↔ 题库）

> 2026-10-24 更新。脚本 v2.10 起默认接站点后端，题库会自动沉淀。

---

## 1. 架构

```
油猴脚本（用户浏览器里）
  ├─ 站点地址 https://xspirt.online        ← 脚本默认值，可改
  ├─ 心跳 5 分钟一次 → /api/public/script-runtime
  │     └─ 后端下发：站点配置、公告、命令、题库地址列表
  ├─ 判分后回写 → /tiku-api/api/pool       ← 进「沉淀池」，不参与匹配
  └─ 答题查询   → /tiku-api/tiku           ← 查「公共池」
                                            ▲
服务器（8080 主后端网关）                      │
  ├─ /tiku-api/*  → 反代到 8091 题库服务    │
  │                 （8091 没放行公网，走 8080 网关最省事）
  └─ 题库服务 8091
        ├─ data/tiku.json   公共池（管理员维护，所有人可用）
        ├─ data/pool.json   沉淀池（脚本自动回写，待审核）
        └─ data/remote-sources.json  外部上游（星夜等）
```

**站点地址为什么不能由后端下发**：脚本端可下发的字段有白名单，`portalServerBase` 不在其中
（防止把用户引到任意地址）。它只能来自脚本默认值或用户手动填。

---

## 2. 用户怎么用

1. 装脚本（油猴里从 GreasyFork / GitHub / 官网安装）。
2. **什么都不用填** —— v2.10 默认已带官方题库地址 `https://xspirt.online/tiku-api/tiku`。
3. 想加自己的题库：面板 → 题库设置 → 添加题库（整段 OCS 风格 JSON 也能粘）。
4. 题库地址会被后端下发的官方题库**合并**进列表（按 url 去重），**不会覆盖**你自己加的。

---

## 3. 题库怎么建（规模化的三条路）

题库的价值不是「覆盖所有题」，而是**高频题走题库（快、准、免费），长尾题走 AI**。
所以目标是「高频覆盖 + 长尾不卡」，不是「题库越大越好」。

### 路线一：外部题库（最快）

- 星夜题库 <https://tiku888.top/>：注册后「个人中心 → 题库配置」复制 JSON。
- 脚本端：面板 → 题库设置 → 添加题库 → 粘贴 JSON（脚本原生兼容 OCS 风格配置）。
- 服务端：填进 `data/remote-sources.json`（复制 `remote-sources.example.json` 改名）。
- ⚠ 免费接口有频率限制，服务端会多源并行 + 失败回退，不会卡死。

### 路线二：自采（最准，答案来自平台判分）

工具：`repos/学习通题目导出.user.js`（批量提取已批阅的作业/测验，导出 JSON）。

```bash
# 直接推进服务器公共池（推荐）
node import.js 你导出的文件.json json --remote https://xspirt.online/tiku-api --key <管理口令>
```

### 路线三：日常沉淀（脚本自动，唯一会自增长的）

脚本在**已批阅的作业/考试页**上读到平台给出的正确答案时，自动回写进**沉淀池**。
沉淀池**不参与匹配**（脏数据污染不到任何人），由管理员审核后才晋升公共池。

**审核流程**：

```bash
# 看沉淀池
curl -H "x-admin-key: <管理口令>" https://xspirt.online/tiku-api/api/pool
# 批量晋升到公共池
curl -X POST https://xspirt.online/tiku-api/api/pool/promote \
  -H "x-admin-key: <管理口令>" -H "Content-Type: application/json" \
  -d '{"ids":["q_xxx","q_yyy"]}'
```

## 4. 质量闸（沉淀池入库前的自动校验）

| 检查 | 不通过时的提示 |
|---|---|
| 题干 4~500 字 | 题干长度需在 4~500 字之间 |
| 答案非空且 ≤80 字 | 答案缺失或过长 |
| 题型合法（单选/多选/判断/填空/简答/论述） | 题型不合法: xxx |
| 选项 2~8 个、无空选项、内容不重复 | 存在空选项 / 选项内容重复 |
| 答案字母必须在选项范围内 | 答案字母不在选项范围内 |
| 单选题只能一个答案、多选题至少两个 | 单选题却给了多个答案 |

另有单 IP 每小时 120 条的限流。**宁可少收，不可收脏。**

## 5. 常用命令

```bash
# 题库服务（服务器上）
sh /tmp/fix-tiku-start.sh          # 重启（带管理口令）
curl -s http://127.0.0.1:8091/api/stats          # 统计
cat /root/.tiku-admin-key                        # 管理口令（600）

# 后端下发的站点配置（改完必须更新 updatedAt，否则脚本不重新应用）
node /tmp/set-script-settings.cjs --reset
node /tmp/set-script-settings.cjs --tiku-url <地址> --tiku-name <名称>
```

## 6. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 脚本查不到题 | 面板里确认官方题库是启用状态；服务器 `curl http://127.0.0.1:8091/api/stats` 看题数 |
| 回写没进沉淀池 | 看脚本日志「已回写题库」；服务端 `curl -H "x-admin-key: ..." .../api/pool/stats` |
| 回写被拒 | 响应里的 msg 就是质量闸的原因（答案不在选项内 / 选项重复 / 题型不合法） |
| 远程导入 500 | 文件带 UTF-8 BOM —— 现在的版本已自动去 BOM；若仍失败，先另存为 UTF-8 无 BOM |
| 脚本收不到后端配置 | 后端 `curl https://xspirt.online/api/public/script-runtime?version=2.10` 看 settings 是否下发 |
| 后端说「已是最新」 | 脚本文件要放到服务器 `/opt/campus_server/脚本/我的脚本.txt`，后端靠它读 @version |
